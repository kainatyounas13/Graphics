# Kainat Younas — Graphic Design Portfolio

## GitHub Pages upload (important)
Upload **all files in this folder together** to the top level (root) of your `Graphics` repository.

Files to upload:
- `index.html`
- `style.css`
- every `.jpg` image in this folder (including `profile-kainat.jpg`)

This version has the JavaScript included inside `index.html`; **there is no separate `script.js` file to upload**. Do not put the files inside another folder. Keep all JPG files beside `index.html`.

After uploading, open `https://kainatyounas13.github.io/Graphics/` and refresh. If the old version remains, wait a minute and refresh again.
